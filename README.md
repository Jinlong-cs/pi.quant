# pi.quant

Company-grade quantization control plane for vision-language-action models.

The first release will connect VLA-aware calibration, intermediate-layer and
action-error analysis, and reproducible evidence to established optimization
backends. v0.1 is under development; it does not claim Pi0.5, FastWAM,
TensorRT, AGX, or RTX 5090 support yet.

See the feature branch and pull request for the v0.1 implementation plan.
